# B.A Dev Lab

**Desenvolvimento • Automação • Tecnologia**

Portfólio de desenvolvimento de **Bruno Ribeiro**, criado para centralizar projetos de software, automação, integração de sistemas e desenvolvimento web.

O B.A Dev Lab funciona como um hub para projetos concluídos e projetos em desenvolvimento, reunindo documentação técnica, estudos de caso, screenshots, repositórios e demonstrações das soluções desenvolvidas.

---

## 🌐 Portfólio

O projeto é publicado através da **Vercel**.

> O endereço público será adicionado aqui após o primeiro deploy.

---

## 🚀 Projetos

### Logistics Automation Hub

Plataforma desktop voltada à gestão e automação de operações logísticas.

O projeto reúne:

- Operations Core;
- controle de fluxo operacional;
- cadastros;
- validação de planilhas;
- Central Operacional;
- alertas;
- relatórios;
- histórico e rastreabilidade;
- persistência local com SQLite.

**Status:** V1.1 Stable

---

### Data Validation Hub

Aplicação para análise, validação e tratamento controlado de dados em planilhas.

Principais conceitos:

- validação configurável;
- identificação de duplicidades;
- revisão humana;
- HUB ID;
- PROC ID;
- geração de arquivos validados;
- histórico de processamentos;
- rastreabilidade.

**Status:** V2.0.0 Stable

---

### Coffee IT Support

Website institucional desenvolvido para apresentação de serviços de tecnologia e como estudo de desenvolvimento web.

O projeto utiliza:

- HTML;
- CSS;
- JavaScript;
- design responsivo;
- acessibilidade;
- integração com WhatsApp;
- Instagram API;
- Vercel Serverless Functions.

**Status:** Publicado

---

### Planner Automation

Automação desenvolvida com Microsoft Power Automate e Microsoft Planner para criação automática de tarefas respeitando uma escala 12x36.

O projeto demonstra:

- automação de processos;
- recorrência;
- cálculo de escala 12x36;
- criação automática de tarefas;
- atribuição;
- vencimentos;
- descrições;
- checklists;
- integração com Microsoft Planner.

**Status:** Em produção / Case documentado

---

### Smart Home Automation API

Projeto de automação residencial destinado à integração entre dispositivos inteligentes, serviços externos e regras personalizadas de automação.

O desenvolvimento será documentado progressivamente no próprio portfólio.

**Status:** Em planejamento

## 🎨 Identidade

O B.A Dev Lab utiliza uma identidade visual própria baseada em uma interface escura com elementos em gradiente e uma paleta formada principalmente por:

```text
#D414C8
#8B2BE2
#2457E6
#0F172A
#E2E8F0
```

A tipografia **Inter** é hospedada localmente no projeto para reduzir dependências externas e manter estabilidade durante o carregamento da interface.

---

## 🔒 Segurança e privacidade

Os projetos públicos seguem o princípio de não publicar informações privadas utilizadas nos ambientes originais de desenvolvimento ou produção.

Isso inclui, quando aplicável:

- tokens;
- credenciais;
- arquivos `.env`;
- identificadores corporativos;
- bancos de dados locais;
- logs;
- informações internas de clientes ou empresas.

Quando necessário, exemplos públicos utilizam dados sanitizados ou placeholders.

## 💻 Desenvolvimento local

Clone o repositório:

```bash
git clone <URL-DO-REPOSITORIO>
```

Entre na pasta:

```bash
cd ba-dev-lab
```

O portfólio é desenvolvido utilizando HTML, CSS e JavaScript e pode ser executado através de um servidor web local.

Por exemplo, utilizando a extensão **Live Server** no Visual Studio Code.
