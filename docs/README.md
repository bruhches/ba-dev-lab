# Portfólio de Projetos — Protótipo 02

Estrutura segmentada para crescimento do projeto.

- `index.html`: único arquivo na raiz.
- `css/`: estilos.
- `js/`: JavaScript e cadastro dos projetos.
- `assets/img/`: imagens e capas dos projetos.
- `api/`: reservado para integrações/API futuras.
- `docs/`: documentação.

## Layout dos projetos

No desktop, os cards são exibidos em duas colunas e em níveis alternados, criando o efeito de escada solicitado. Em telas pequenas o deslocamento é removido para preservar a leitura e a responsividade.
